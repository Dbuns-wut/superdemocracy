# Superdemocracy — Book Set

Three reading depths of the Superdemocracy project. Read shortest first.

## 1. [superdemocracy-project-primer.md](superdemocracy-project-primer.md)

**Use for:** developers, AI agents, researchers, collaborators, and new contributors who need the fastest serious explanation of the project. Read this before the technical Master Plan.

## 2. [superdemocracy-the-experiment-condensed.md](superdemocracy-the-experiment-condensed.md)

**Use for:** a coherent one-sitting book read. Reorganizes the central ideas into a cleaner narrative: the problem with current democratic machinery, the Swiss/Taiwan/technology discoveries, the Superdemocratic decision process, delegation, experimentation, security, AI, and the long-term constitutional-intelligence idea.

## 3. [superdemocracy-full-manuscript.md](superdemocracy-full-manuscript.md)

**Use for:** founding philosophy, original arguments, examples, intellectual history, and the complete long-form manuscript. A cleaned repository reading edition; it intentionally preserves older ideas even where later project documents refined the implementation.
