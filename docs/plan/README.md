## Authority when documents conflict

1. **Current code** defines what actually exists.
2. Preserve **democratic sovereignty** and **vote secrecy**.
3. Preserve the [north star](north-star.md) and [governance principles](governance-principles.md).
4. Consult the [master plan](master-plan.md) and [system specification](system-specification.md).
5. Consult the [security architecture](security-architecture.md) for security/privacy.
6. Consult the [decision log](research-and-decisions.md).
7. The founding book is intellectual history when later documents refined implementation.

Record conflicts in [research-and-decisions.md](research-and-decisions.md) instead of silently picking a side.

Do not commit local Anvil keys or other `03-DEV-ONLY` credentials.
