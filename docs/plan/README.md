## Authority when documents conflict

1. **Current code** defines what actually exists.
2. **North star** is the intended direction.
3. **System specification** is the intended software architecture.
4. **Security architecture** is non-negotiable for votes and identity.
5. **Research and decisions** records evidence, hypotheses, and choices.
6. The founding book is intellectual history. It is not automatically a technical requirement when later decisions changed the design.

Record conflicts in [research-and-decisions.md](research-and-decisions.md) instead of silently picking a side.

Do not commit local Anvil keys or other `03-DEV-ONLY` credentials.
